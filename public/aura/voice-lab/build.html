Rebuild this voice application

Download and unpack phonemizer-source.tar.gz. It contains the full pinned eSpeak tree, ucd-tools source, original license notices and compatibility patch. Install Emscripten 4.0.10 and a native C/C++ compiler, CMake, Python 3 and Node 22. Activate emsdk_env.sh, then run bash scripts/build-all.sh. This compiles native dictionaries, static WASM libraries and the final dist/wasm module. All local changes are included.

Copy src/*.mjs into vendor/phonemizer/src/, dist/wasm/* into both vendor/phonemizer/dist/wasm/ (module import) and vendor/phonemizer/wasm/ (runtime locator), and dist/data/* into vendor/phonemizer/data/. The application imports the wrapper source directly. It passes an explicit local base path; external CDN fallback was removed.

Install onnxruntime-web@1.31.1 and esbuild@0.28.2, then bundle source.js with esbuild --bundle --format=esm --platform=browser --external:node:* --external:module and alias onnxruntime-web/wasm to onnxruntime-web/dist/ort.wasm.bundle.min.mjs. Output app.js. Copy ONNX Runtime's ort-wasm-simd-threaded.mjs and .wasm into vendor/.

Model: concatenate models/model-0.bin through model-4.bin for the original model_quantized.onnx from the linked Kokoro model repository. tokenizer.json and float32 voice vectors hf_alpha.bin and af_heart.bin come from the same repository. Voice synthesis needs model assets, not the source archive. Language data loads on demand. Serve over HTTPS with script-src 'wasm-unsafe-eval' enabled only for this voice route. Rebuilding may produce byte differences with another toolchain.

Source archive includes vendor license files. ONNX Runtime MIT and third-party notices and Kokoro Apache-2.0 text are provided separately. All application source is unobfuscated and available alongside the generated bundle. No secrets or server account code are part of this client.
