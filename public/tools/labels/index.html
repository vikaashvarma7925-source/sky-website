SKY Studio tool

Label and sticker sheet

Make a printable A4 sheet of labels, like name stickers.

Your text stays in this page. Nothing is uploaded or saved. The grid divides an A4 page equally. It is not matched to a specific sticker brand, so if you print on ready-made sticker paper, test one plain page first and hold it against the sticker sheet. Print at 100 percent ("Actual size"), not "Fit to page". Long text is cut at the edge of the label.
