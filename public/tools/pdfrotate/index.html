Which pages?

The file stays on your device and is not uploaded. The pages are turned in the new file, and everything else in the file is kept as it is. Your original file is not changed. The new file is saved on your device like any other download. Open it and check the pages before you send it. There is no page preview here, so check the page numbers on your own copy.
