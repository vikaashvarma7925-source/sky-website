SKY Studio tool

Add watermark to PDF

Put your own text, like DRAFT or a name, across the pages of a PDF.

Which pages?

The file stays on your device and is not uploaded. The text is added on top of each page, in the middle. It is normal text in the file, so a person with a PDF editor can still remove it. It does not protect the file. Your original file is not changed. The new file is saved on your device like any other download. Open it and check every page before you send it.
