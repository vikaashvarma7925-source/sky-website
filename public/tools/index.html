SKY Studio

Tools

Free tools that run inside your browser. Your files are not uploaded.

  • Word counterCount words and characters as you type.
  • Duplicate line removerRemove repeated lines from a list.
  • Lucky drawPick winners at random from a list of names.
  • TeleprompterScroll your script on screen while you record or speak.
  • Handwriting practice sheetPrintable lines with light letters to trace.
  • OMR answer sheet makerPrintable bubble sheet for a test.
  • Label and sticker sheetPrintable A4 sheet of labels, like name stickers.
  • Invoice makerType items, check the total, print or save as PDF.
  • Resume makerType your details, print or save a clean one-column resume.
  • Menu makerType items and prices, print or save a clean menu.
  • Certificate makerType a name and words, print or save a certificate.
  • Biodata makerType your details, print or save a clean biodata sheet.
  • Audio cutter and joinerChoose one or more audio files, set where each one starts and ends, and save one joined WAV file.
  • Budget plannerType your monthly income and expenses. See the total, what is left, and how much of your income each expense takes. Print or save as PDF.
  • E-book makerType your title and chapters, then save an EPUB file that e-book reader apps can open.
  • Flashcard makerType your cards, practise on this page, or print cards to cut and fold.
  • Habit trackerMake a one-month habit sheet. Tick the days on this page, or print it and tick with a pen.
  • Photos to PDFPut photos or scans into one PDF, one photo per page.
  • Image format converterChange photos between JPG, PNG and WebP.
  • Invitation card makerType the details, check the card, then print or save as PDF. It prints on one A4 page.
  • Application letter makerPick a letter type and a language, fill the boxes, edit the words if you want, then print or save as PDF. It prints on one A4 page.
  • Merge PDFsJoin several PDF files into one, in the order you choose.
  • Protect PDF with a passwordLock a PDF so it asks for a password before it opens.
  • Rotate PDFTurn all pages, or only some pages, and save a new PDF.
  • Split PDFTake some pages out of a PDF, or cut it into several smaller files.
  • PDF unlockRemove the open-password from a PDF that is yours, when you already know the password.
  • Add watermark to PDFPut your own text, like DRAFT or a name, across the pages of a PDF.
  • Salary slip makerType the real pay details, check the totals, then print or save as PDF. It prints on one A4 page.
  • Photo scannerTake a photo of a paper. Straighten it and clean it so it looks like a scan.
  • Excel and CSV viewerOpen an .xlsx or .csv file and read it as a table. This tool only shows the file. It does not change it.
  • Study timetableMake a weekly timetable, fill the boxes, then print it on one A4 page.
  • Contacts CSV to VCFTurn a contacts spreadsheet (CSV) into a file your phone can import.
  • Video to GIFMake a short silent GIF from a part of a video.
  • Video frame saverPick a moment in a video, crop it if you want, and save that frame as a picture.
  • ZIP maker and openerPut files into one ZIP, or open a ZIP and save the files you need one by one.
