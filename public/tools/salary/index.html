SKY Studio tool

Salary slip maker

Type the real pay details, check the totals, then print or save as PDF. It prints on one A4 page.

Earnings (amount in rupees, like 25000 or 25,000.50)
Deductions (amount in rupees)

Everything you type stays in this page. It is not uploaded or saved. This tool only lays out the numbers you type. It does not know your tax or PF rules, so check every amount. The slip is a plain statement. It is not an official document unless your employer signs and stamps it. Use it only for real pay details. When you save a PDF, it is stored on your device like any other file.
