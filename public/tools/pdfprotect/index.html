SKY Studio tool

Protect PDF with a password

Lock a PDF so it asks for a password before it opens.

If you forget this password, nobody can open the new file, and this tool cannot get it back. Write the password down and keep your original file safe.

The file and the password stay on your device. Nothing is uploaded, and this page does not keep them after you close it. The new file is locked with AES-256 encryption and asks for the password before it opens. Modern PDF readers such as Chrome, Edge, Firefox, Adobe Reader and Apple Preview can open it, but very old readers may not. This tool does not set limits on printing or copying, because those limits are not reliable. Your original file is not changed and has no password, so delete or store it safely yourself. The new file is saved on your device like any other download. Open it once with the password to check it before you send it.
