PDF unlock

Remove the open-password from a PDF that is yours, when you already know the password.

Use this only for your own files, or files you have permission to unlock. You must type the password. This tool does not guess or crack passwords.

Download unlocked PDF

The file and the password stay on your device. Nothing is uploaded, and this page does not keep them after you close it. When you press Download, the unlocked PDF is saved on your device like any other download, so delete it yourself if you do not want to keep it. It has no password, so anyone who gets the file can open it. Check that it opens properly before you delete the original.
