SKY Studio tool

Excel and CSV viewer

Open an .xlsx or .csv file and read it as a table. This tool only shows the file. It does not change it.

Your file is opened on this device and is not uploaded or saved by this tool. Limits: the first 1000 rows and 50 columns of each sheet are shown, and the page says when more exist. Text is shown as stored. Dates in date-formatted cells are shown as year-month-day, and times as hours:minutes. Simple percent, decimal, thousands and currency formats are applied; other number formats are not, and the page says how many cells that affects. Long whole numbers (like ID numbers) are shown in full as stored. Formulas show the result saved in the file; this tool does not calculate. Only open files from people you trust.
